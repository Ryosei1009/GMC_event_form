# 🎉 GMC RP 2 周年イベント アイテム申請フォーム

**2 周年フリーマーケットに出店するプレイヤーが、オリジナル商品をブラウザから申請できる Web アプリ**

※ イベントは終了し、申請は締め切りました

</div>

GTA5 のロールプレイサーバー「GMC RP」の 2 周年イベントで開いた「フリーマーケット」のために作った Web アプリです。
出店するプレイヤーが、自分で考えたオリジナルアイテムを申請できます。
運営は申請内容を確認し、ゲームに組み込むコードをそのままコピーして反映できます。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
このフォームは、以前作った「新商品申請フォーム」の仕組みを流用し、イベント向けに作り直しました。

## 主な機能

| 画面 | 使う人 | 内容 |
| --- | --- | --- |
| 📝 **アイテム申請** | 出店するプレイヤー | CitizenID、アイテム名、説明、画像、種類、オプションを入力して申請 |
| 📋 **申請済みアイテム** | 出店するプレイヤー | 申請した後は、自分が申請したアイテムを確認できる画面に切り替わる |
| 🛠️ **申請一覧（管理画面）** | 運営 | すべての申請を確認し、ゲーム用の Lua コードをコピー |

### 申請できるアイテムの種類

| 種類 | 内容 |
| --- | --- |
| 📦 基本アイテム | ふつうのアイテム |
| 🕺 エモートアイテム | 使うとエモート（キャラクターの動き）を再生 |
| 🖼️ 画像表示アイテム | 使うと画像を表示 |
| 🎵 音楽再生アイテム | 使うと音楽を再生 |

オプションとして、「使ったらアイテムを消す」か「使っても消さない」かを選べます。

## 工夫したところ

### 既存の仕組みを流用して短期間で公開

イベントの申請受付に間に合わせるため、「新商品申請フォーム」で作ったフォーム、プレビュー、コード生成の仕組みを流用しました。
イベントで必要な項目だけに絞ってテーブルを作り直し、限られた準備期間で申請の受付を始められました。申請は 2 月 12 日に締め切りました。

### 申請ミスを防ぐ入力フォーム

- CitizenID（ゲーム内のキャラクター ID）は 8 文字ちょうどでないと送信できず、ゲーム画面のどこに書いてあるかを画像で案内しています
- アイテム名は 30 文字、説明は 60 文字、エモート名は 15 文字までで、入力中に文字数を表示します
- 画像は PNG で 5 MB までに限定しています
- 送信前にプレビューで仕上がりを確認できます

### アカウントなしで自分の申請を確認

申請すると CitizenID がブラウザ（`localStorage`）に保存され、次に開いたときは自分の申請済みアイテムの画面が表示されます。
出店者にアカウントを作ってもらう必要はありません。

### 運営の反映作業を最小限に

- アイテム ID や画像・音声のファイル名は CitizenID から自動で決まるので、運営が名前を考える必要がありません
- アイテムの種類ごとに、ゲームに組み込む Lua のコードを自動で作ります
- コードは Prism.js でハイライトし、ボタン 1 つでコピーできます

## 技術スタック

| | |
| --- | --- |
| **Frontend** | React 18, React Router, Tailwind CSS, Headless UI, Prism.js |
| **Backend** | Node.js, Express, MySQL, JWT（GMC RP のほかのツールと共通の API サーバー） |
| **Infra** | Vercel（フロント）, Vercel Analytics |

```
出店するプレイヤー ──▶ アイテム申請 ──┐
                                      ├─▶ API サーバー（Express）──▶ MySQL
運営 ──▶ 申請一覧（JWT でログイン）───┘
             │
             └─▶ Lua コードをコピーしてゲームサーバーに反映
```

このリポジトリにはフロントエンドのコードと、テーブル定義（`database.sql`）だけを入れています。

## ディレクトリ構成

```
src/components/
├── newitem/          # アイテム申請フォーム（入力、画像、プレビュー）
├── newitem_list2/    # 出店者向けの申請済みアイテム
├── newitem_list/     # 運営向けの申請一覧と Lua コード生成
└── utils/            # ヘッダー、フッターなどの共通部品
```
